## Goal
在不引入任何 OS/RTOS、不使用堆、不使用线程的前提下，让 nanosig 的 **signal/slot** 与 **timer** 两个子系统能在裸机 MCU 上工作：库内保留"emit 只入队、回调异步派发"的语义，但把派发权从 broker 线程移交给用户 main 循环里的单次 `ns_loop_poll()`；裸机内建**一个静态 loop 实例**；平台后端只提供 3 个符号（`init` / `shutdown` / 单调时钟），其余平台原语连同其核心层调用点一起用 `NANOSIG_BAREMETAL` 条件编译屏蔽。

## Constraints
- **范围内只有 signal/slot + timer。** `ns_watcher_*`、`ns_broker_*`、waitset、event、thread 全部不在裸机范围内。
- **异步派发语义必须保留。** `ns_signal_emit()` 只把调用入队，**不得**当场同步调用 slot 回调；真实回调在 `ns_loop_poll()` 中发生。
- **单一静态 loop。** 裸机后端内建一个 loop 的静态存储；第一次 `ns_loop_create()` 返回该实例，之后禁止创建第二个实例。
- **驱动接口是 `ns_loop_poll(ns_loop_t *loop, uint32_t max_wait_us)`。** 单次调用内完成：drain MPSC ring → 派发 slot 回调 → 检查 timer_mgr 到期 → 派发到期 timer。返回后控制权回到用户主循环；`max_wait_us == 0` 为非阻塞。
- **裸机后端只提供 3 个平台符号：**
  - `ns_platform_init`、`ns_platform_shutdown`（可为空实现）
  - `ns_platform_clock_monotonic_us`（唯一有实质内容的函数）
  - 其余 `ns_platform_alloc/free`、`mutex_*`、`wakeup_*`、`event_*`、`waitset_*`、`thread_*` **一律不提供符号**。
- **时钟钩子契约：** 用户提供一个返回 **uint64 微秒、单调不减、永不回绕** 的时钟函数；`ns_platform_clock_monotonic_us()` 直接转调它。**库内不做 tick 换算、不做回绕扩展**，回绕责任完全在应用侧。
- **零堆：** signal+timer 全路径不得有任何分配。`ns_platform_alloc/free` 不提供符号，因此其所有调用点必须被条件编译屏蔽。
- **定时器到期判定与派发绝不在中断上下文。** 消除对 ISR 安全的全部要求。
- **"其余 API 不定义" 落点：** 未支持的模块级 API 与平台原语**直接不产生符号**，引用它们的程序在链接期失败（可诊断）。不提供返回 `NS_E_UNSUPPORTED` 的桩，也不提供静默 `NS_OK` 的空实现。
- **允许改动 `src/` 核心层**，通过 `NANOSIG_BAREMETAL` 条件编译排除 broker、线程路径，以及 mutex / wakeup / alloc 的调用点与对应结构体成员（`ns_signal_t.mutex`、`ns_loop_t.wakeup`、`ns_timer_mgr.mutex`、`ns_dbg_mutex`、`ns_formatio` 的溢出分配分支）。
- **既有分层约束不得破坏（精确表述）：** `src/` 与 `include/nanosig/` 中**不得新增任何 OS 身份宏**（`_WIN32` / `__linux__` / `__APPLE__` / `FreeRTOS` / `Zephyr`）；裸机判定只能有 `NANOSIG_BAREMETAL` 一个宏（由 `platform/baremetal/nanosig_platform_port.h` 定义），且它在 `include/nanosig/` 中**仅允许**作为 `nanosig_signal.h` 的成员声明守卫出现，在 `src/` 中仅允许出现在白名单 `{nanosig.c, ns_timer.c, ns_debug.c, ns_formatio.c}`。
- **必须满足 `platform/README.md`「新增后端清单」全部 7 项**，且不得修改其他后端实现文件、不得改 `nanosig_port.h` 既有接口签名（只能新增扩展点）。
- 桌面三后端（Linux/macOS/Windows）与 FreeRTOS/Zephyr 后端的既有行为**零回归**。

## Non-Goals
- ISR 上下文 emit / `*_from_isr` 系列 API。
- watcher、broker、waitset、event、thread 在裸机上的任何功能。
- 多 loop 实例（并发 loop、`ns_loop_start` 的线程化运行）。
- 库内 tick 回绕扩展、tick→微秒换算（责任在用户时钟钩子）。
- 裸机上使用 `ns_hashtbl`（不编入裸机构建）。
- 真实 MCU 上的 tick 精度、栈深度、`configASSERT` 类硬件行为验证（归硬件冒烟，与 FreeRTOS 后端 docs 的既有划分一致）。
- SMP / 多核裸机。
- 修改或重写 FreeRTOS / Zephyr / 桌面后端。
- 让用户注入任意分配器（第 9–10 轮已否决，改为彻底零堆）。

## Technical Context

### 平台层契约现状
- `include/nanosig/nanosig_port.h` 是唯一 OS 耦合点，含 12 组 `extern` 平台函数：`init/shutdown`、`alloc/free`、`wakeup_{init,deinit,signal,wait}`、`event_{init,signal,drain,deinit}`、`mutex_{init,deinit,lock,unlock}`、`clock_monotonic_us`、`thread_{stack_range,init,join}`、`waitset_{init,deinit,add,remove,wait}`。
- 平台类型由固定名构建内头 `platform/<backend>/nanosig_platform_port.h` 注入（`NANOSIG_PLATFORM_DIR` 走 include 路径），`nanosig_port.h` 本身不含平台判定宏。裸机后端头必须提供 `ns_waitable_handle_t` + `ns_waitable_handle_is_valid`、`NS_PLATFORM_ABI_PROBE`，以及被保留下来的结构体成员所需的类型（`ns_platform_mutex_t` / `ns_platform_wakeup_t` 在成员被条件编译移除后可退化为空类型）。
- 现有 5 后端：`platform/{linux,macos,windows,freertos,zephyr}/`。

**未修订但已知的取值取舍**（不是矛盾，是设计选择，记录备查）：

- `ns_formatio` 在裸机下对超宽数值（`%b` ≥ 2^16、`%o` ≥ 16 位、`%llu` ≥ 10^16）输出为空串，且 `ns_snprintf` 返回偏短计数而非错误——这与既有"分配失败"路径行为一致。
- `ns_loop_destroy` 在裸机下遇到未派发记录时**直接丢弃**（与 host 同语义），可诊断性留给后续的 `ns_loop_stats()`。
- 裸机 loop 的 ring 容量恒为编译期常量 `NANOSIG_BAREMETAL_LOOP_QUEUE_BYTES`；`queue_byte_capacity` 大于它返回 `NS_E_INVAL`，不大于时实际容量仍为该常量（`loop->config` 记录的是实际值）。
