# proposals — 想法与提案

本目录存放**尚未批准**的设计想法、方向性提案与备选方案。

## 与其它目录的区别

| 目录 | 内容 |
|------|------|
| `docs/specs/` | 已收口的需求规格、需求访谈 |
| `docs/plans/` | 已批准/在执行/已完成的中文实施计划（子计划） |
| `docs/proposals/` | **未批准**的想法与提案，可能是草案、备选方案、待评审方向 |
| `docs/review/` | 代码审查发现与闭环记录（遵守 `docs/review/AGENTS.md`） |

## 约定

- 每份提案在头部标注状态，如 `- 状态: **提案**（待评审；未批准实施）`。
- 命名：`<主题>提案.md`。
- 提案**不是实现依据**：未批准前不得据此改动代码；批准后如进入实施，迁移为 `docs/plans/` 下的子计划或直接落地。
- 提案不进入 review 流程；review 相关内容仍只写在 `docs/review/` 下。
- 提案被否决时保留原文，并在头部记录裁决结果与日期（不删除）。
